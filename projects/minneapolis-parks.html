PYTHON · GEOPANDAS · FOLIUM

Minneapolis Neighborhood Parks & Trails

An interactive web map exploring park area and trail access across Minneapolis neighborhoods.

Tools

Python, GeoPandas, Folium

Project Type

Spatial Analysis & Interactive Mapping

Study Area

Minneapolis, Minnesota

Overview

Access to recreation outdoor recreation space is vital for people's health and quality of life. This project was developed as a tool to evaluate nighborhood level access to parks and trails across Minneapolis. I've also found it to be a great resource to refer to when I'm curious about what neighborhood a location is in!

Neighborhood, park, and trail datasets were processed with GeoPandas. The results were then presented using Folium to create an interactive web map.

Explore the map

Click on a neighborhood, or find it in the search menu to see statistics about its trails and greenspace.

Methods

01

Data Preparation

Sourced datasets and read them into GeoPandas.

02

Spatial Analysis

Used GeoPandas to analyze park area and trail length within individual Minneapolis neighborhoods.

03

Interactivity

Built an interactive Folium map allowing users to select neighborhoods and explore parks, trails, and calculated statistics.
